# نرم‌افزار حسابداری و مدیریت انبار و فروشگاه

نرم‌افزار جامع مدیریت حسابداری، انبار، فاکتور خرید و فروش، مشتریان و صندوق.

## 🚀 روش ساخت فایل اجرایی برنامه (`.exe` برای ویندوز)

### روش ۱: ساخت خودکار در گیت‌هاب (پیشنهادی و بسیار آسان)
1. این پروژه را از منوی تنظیمات بالا به ریپازیتوری **GitHub** خود خروجی (Export) بگیرید.
2. وارد ریپازیتوری خود در GitHub شوید و به تب **Actions** بروید.
3. اکشن **Build Windows EXE** به‌صورت خودکار اجرا می‌شود (یا می‌توانید دکمه **Run workflow** را بزنید).
4. پس از اتمام ساخت (حدود ۲ الی ۳ دقیقه)، فایل‌های خروجی نصب‌کننده (`.exe`) در بخش **Artifacts** یا Releases آماده دانلود مستقیم خواهند بود!

---

### روش ۲: ساخت فایل `.exe` در کامپیوتر شخصی (Windows)
اگر پروژه را روی کامپیوتر خود دانلود کرده‌اید:

۱. نرم‌افزار [Node.js](https://nodejs.org) را روی سیستم خود نصب کنید.
۲. ترمینال یا CMD را در پوشه پروژه باز کنید و دستورات زیر را اجرا کنید:

```bash
# نصب وابستگی‌ها
npm install

# ساخت فایل .exe ویندوز
npm run package:win
```

۳. فایل اجرایی نصب‌کننده و نسخه پرتابل در پوشه `release/` با نام **`سیستم حسابداری و انبارداری Setup 1.0.0.exe`** ساخته خواهد شد!

---

## 🛠️ ساختار فایل‌های دسکتاپ
- `electron.js`: فایل تنظیمات پنجره دسکتاپ و محیط Electron
- `vite.config.ts`: پیکربندی خروجی با مسیردهی نسبی (`base: './'`)
- `.github/workflows/build-exe.yml`: اکشن هوشمند ساخت خودکار فایل ویندوز روی گیت‌هاب
